JavaScript if, else, and else if

Very often when you write code, you want to perform different actions based on different conditions. You can use conditional statements in your code to do this. In JavaScript, we have the following conditional statements:

  • if: Specifies a block of code to be executed if a specified condition is true.
  • else: Specifies a block of code to be executed if the same condition is false.
  • else if: Specifies a new condition to test if the first condition is false.
  • switch: Specifies many alternative blocks of code to be executed.
